## 📌 프로젝트 소개
[프로젝트 이름]은 복잡한 입력 없이 세트 수, 무게, 반복 횟수(Reps), RIR을 빠르게 기록하고, 
볼륨 변화와 점진적 과부하 달성 여부를 직관적으로 시각화해 주는 헬스 기록 애플리케이션입니다.

## ✨ 주요 기능
- **간편한 세트 기록:** 이전 세트 중량/횟수 자동 불러오기 및 휴식 타이머 연동
- **점진적 과부하 트래킹:** 주간/월간 운동 볼륨 및 추정 1RM 추이 그래프 제공
- **맞춤형 루틴 설정:** 부위별·분할별 커스텀 루틴 생성 및 관리
